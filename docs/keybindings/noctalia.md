# Noctalia Keybindings

**Source**: `modules/home/noctalia/main.nix` (keybinds section)

---

## Global Navigation

| Key | Action |
|-----|--------|
| `Escape` | Cancel |
| `Up` / `Down` / `Left` / `Right` | Navigate |
| `Return` / `KP_Enter` | Validate/Select |

---

## Session Shortcuts (lockscreen / session menu)

| Key | Action |
|-----|--------|
| `1` | Lock |
| `2` | Logout |
| `3` | Lock and suspend |
| `4` | Reboot |
| `5` | Shutdown (destructive) |

## Panel Interaction

| Action | Trigger |
|--------|---------|
